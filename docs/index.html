Пейны — создать split #

ШорткатДействие
Ctrl+Shift+\Split → новый пейн справа (SplitHorizontal)
Ctrl+Shift+-Split → новый пейн снизу (SplitVertical)
Терминология WezTerm. SplitHorizontal кладёт пейн справа (вертикальная линия раздела), SplitVertical — снизу (горизонтальная линия). Символы \ и - повторяют направление разделителя.
